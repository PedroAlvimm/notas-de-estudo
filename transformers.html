Notas da aula 1 de Stanford CME295 (Transformers & LLMs, outono de 2026), de Afshine e Shervine Amidi: vídeo da aula. Resumo e exemplos com minhas palavras.

1.1Como chegamos aqui

  • Nos anos 2010, cada tarefa tinha seu modelo: um para sentimento (positivo, negativo, neutro), outro para tradução, outro para achar nomes e lugares.
  • A virada de 2017 foi a escala: com mais dados, mais computação e mais parâmetros, o Transformer melhora muito mais que os modelos anteriores.
  • Os LLMs de hoje são Transformers ampliados, tanto no tamanho do modelo quanto no número de tokens de treino.

1.2Tokenização

  • Modelos só entendem números. O primeiro passo é dividir o texto em pedaços indivisíveis, os tokens.
Acuteteddy bearisreading.
  • Aqui são 6 tokens: esse é o tamanho da sequência.
  • Vocabulário = a lista de todos os tokens permitidos.
  • Vocabulário maior gera sequências mais curtas. Vocabulário menor gera sequências mais longas.
  • Isso importa porque o custo do modelo cresce com o tamanho da sequência.

1.3Três jeitos de tokenizar

NívelPrósContras
PalavraSimples e fácil de interpretar.Vocabulário enorme (bear, bears...). Não aproveita a raiz das palavras. Risco de palavra fora do vocabulário (OOV).
CaractereVocabulário pequeno, sem OOV. Tolera erros de digitação.Sequências muito longas, então fica lento. Embeddings difíceis de interpretar.
SubpalavraAproveita raízes: read + ing. Aprendida dos dados.Precisa treinar o tokenizador. Depende do texto usado no treino.

Subpalavra é o padrão nos LLMs atuais.

1.4BPE: Byte Pair Encoding

O tokenizador de subpalavra mais usado. Ele aprende o vocabulário assim:

  1. Começa com um vocabulário pequeno, como todas as letras.
  2. Conta no texto de treino qual par vizinho aparece mais. Ex.: em "desfazer, desligar, desconto", o par d + e.
  3. Junta o par num token novo ("de") e coloca no vocabulário.
  4. Repete ("de" + "s" vira "des") até chegar ao tamanho desejado.
  • LLMs atuais usam vocabulários na casa das centenas de milhares de tokens (ex.: ~200 mil), cobrindo vários idiomas.
  • Treine o tokenizador com textos parecidos com o uso real. Um tokenizador treinado só em inglês quebra o português em muitos pedaços.

1.5Tokens especiais

TokenPara quê

[BOS]Início da sequência: avisa o modelo para começar a gerar.
[EOS]Fim da sequência: o modelo avisa que terminou.

Os nomes mudam de modelo para modelo: <s>, </s>, <|endoftext|>...

1.6Embeddings: one-hot vs aprendido

  • One-hot: cada token vira um vetor do tamanho do vocabulário, com um único 1. "soft" = [1, 0, 0, 0...].
  • Problema: todos os one-hots são ortogonais (produto escalar = 0). "teddy bear" fica tão longe de "soft" quanto de "book".
  • O que se quer é um embedding aprendido: um vetor denso com D números (D bem menor que o vocabulário V), em que tokens parecidos ficam próximos.
  • Por quê? Para prever a próxima palavra ou classificar um texto, o modelo precisa de representações que carreguem significado.
ParOne-hotAprendido
teddy bear · soft0alto
teddy bear · book0baixo

1.7word2vec (2013)

  • Aprende embeddings com uma tarefa auxiliar (proxy): prever palavras a partir do contexto.
  • CBOW: prevê a palavra do meio a partir das vizinhas. Skip-gram: prevê as vizinhas a partir da palavra do meio.
  • O erro é medido com cross-entropy, e os pesos se ajustam por backpropagation.
  • Depois do treino, a camada do meio é o embedding. As analogias aparecem sozinhas: Paris está para França assim como Berlim está para Alemanha.

1.8Limitações do word2vec

  • Um vetor por palavra, não importa o contexto. "banco" de praça e "banco" de dinheiro ficam com o mesmo embedding. Um "que fofo!" sincero e um irônico também.
  • Ignora a ordem. "A criança abraça o urso" e "o urso abraça a criança" têm as mesmas palavras e viram os mesmos vetores.
  • Palavra nunca vista no treino não tem vetor.
  • Essas limitações levaram às RNNs e, depois, à atenção: representações que dependem da frase inteira.

2. Da RNN à Atenção

Pág. 2/3

2.1RNN: rede recorrente

  • Lê um token por vez e guarda um estado oculto (h) que resume a frase até ali.
  • Cada passo recebe o token atual mais o estado anterior. Assim a ordem das palavras passa a contar.
  • Era usada para classificar frases (sentimento), rotular cada palavra (substantivo ou verbo) e gerar texto.

2.2Os problemas da RNN

  • Memória curta: a frase inteira precisa caber num único vetor, que vai sendo sobrescrito. O que veio há muito tempo se perde. Esse é o problema da dependência de longo alcance.
  • Exemplo: "Meu urso de pelúcia é tão fofo. [...duas frases depois...] Ele tem 1 metro." A quem o "ele" se refere?
  • Causa técnica: o vanishing gradient. O sinal de erro vai sumindo ao voltar por muitos passos no treino.
  • LSTM (Long Short-Term Memory) adiciona um cell state para carregar informação por mais tempo. Melhora, mas não resolve.
  • Lenta: processa um token de cada vez, então não dá para paralelizar o treino.

2.3A ideia da atenção

  • Em vez de depender só do estado oculto, o modelo cria conexões diretas com os tokens anteriores e aprende quais importam.
  • Na tradução: para escrever a próxima palavra em francês, ajuda olhar direto para a palavra em inglês que está sendo traduzida.
  • Self-attention (2017) leva isso ao extremo: a representação de cada token é calculada a partir de todos os tokens da sequência.
  • Sem recorrência: todos os tokens são processados em paralelo.
  • Atenção: sozinha, ela não sabe a ordem das palavras. Por isso entra o embedding de posição (seção 3.2).

2.4Query, Key e Value

VetorPergunta que responde
Query (Q)O que este token está procurando?
Key (K)O que cada token oferece para ser encontrado?
Value (V)Que informação cada token entrega se for escolhido?
  • Peso = o quanto a query combina com cada key (produto escalar). A nova representação é a média ponderada dos values.
  • Q, K e V saem do mesmo embedding multiplicado por 3 matrizes aprendidas: WQ, WK e WV.

2.5A fórmula da atenção

Attention(Q, K, V) = softmax( QKT√dk ) · V

Lendo a fórmula, passo a passo

  1. QKT gera uma matriz n × n. A célula (i, j) é qi · kj: o quanto o token i combina com o token j.
  2. ÷ √dk: com vetores grandes, os produtos crescem demais e o softmax fica extremo. Dividir mantém a escala estável.
  3. softmax em cada linha: os valores viram pesos positivos que somam 1.
  4. × V: cada linha da saída é Σj pesoij · vj, a média ponderada dos values.

A matriz de atenção tem n × n: dobrar o tamanho da sequência quadruplica o custo. Os professores avisaram que essa é a fórmula mais importante do curso.

import numpy as np

def atencao(Q, K, V, mascara=None):
    dk = K.shape[-1]
    scores = Q @ K.T / np.sqrt(dk)        # (n, n)
    if mascara is not None:
        scores = np.where(mascara, scores, -np.inf)
    # softmax em cada linha
    pesos = np.exp(scores - scores.max(-1, keepdims=True))
    pesos = pesos / pesos.sum(-1, keepdims=True)
    return pesos @ V                       # (n, d_v)

n = número de tokens. A dimensão da query tem de ser igual à da key (dq = dk), senão o produto QKT não existe.

2.7Multi-head attention

  • Em vez de uma atenção, rodam h atenções em paralelo (no original, h = 8), cada uma com seus próprios WQ, WK e WV.
  • Cada cabeça pode aprender um tipo de relação diferente, como adjetivo com substantivo ou pronome com o nome a que se refere.
  • As saídas são concatenadas (n × h·dv) e projetadas por WO de volta para dmodel.
  • É parecido com usar vários filtros numa CNN de visão computacional.
  • Entra dmodel e sai dmodel: por isso dá para empilhar várias camadas iguais.

3. A Arquitetura Transformer

Pág. 3/3

3.1Visão geral: encoder e decoder

  • O artigo de 2017 era sobre tradução automática (inglês para francês e para alemão).
  • Encoder: lê a frase de origem e entrega um vetor rico por token, que leva em conta a frase inteira.
  • Decoder: gera a tradução token a token, usando o que já gerou e a saída do encoder.
  • Os LLMs atuais, como o GPT, usam só uma parte disso (o decoder). As próximas aulas mostram como.

3.2Entrada: embedding de posição

  • A self-attention não sabe a ordem. Por isso se soma ao embedding do token um embedding da posição, do mesmo tamanho (dmodel).
  • Aprendido: simples, mas não funciona para posições maiores que as vistas no treino. Treinou até 500, chegou um texto com 1.000? Não tem vetor.
  • Senoidal (fixo): senos e cossenos em frequências diferentes. PE(pos, 2i) = sin(pos / 100002i/d) e cos nas posições ímpares.
  • Analogia do relógio: os ponteiros de horas, minutos e segundos giram em velocidades diferentes, e juntos dizem a hora exata.
  • Posições próximas geram vetores parecidos. Posições distantes geram vetores diferentes.

3.3O encoder

São 6 blocos iguais, um em cima do outro. Cada bloco faz:

  1. Self-attention multi-head: cada token olha para todos os outros.
  2. Add & Norm: conexão residual e normalização.
  3. Feed-forward: rede com uma camada oculta, aplicada a cada token. Expande dmodel para dff (de 512 para 2048) e volta, com uma ativação não linear.
  4. Add & Norm de novo.
  • É no feed-forward que fica a maior parte dos parâmetros, ou seja, da capacidade de aprender.
  • Saída: um vetor por token, ciente da frase inteira.

3.4O decoder

  1. Começa com o token [BOS] (mais a posição).
  2. Self-attention mascarada: cada token só vê a si mesmo e os anteriores.
  3. Cross-attention: a query vem do decoder, a key e o value vêm da saída do encoder. É aqui que a tradução "consulta" a frase original.
  4. Feed-forward e Add & Norm, também em 6 blocos.
  5. Linear + softmax: transforma o vetor numa probabilidade para cada token do vocabulário.
  6. Escolhe o próximo token (ex.: o mais provável), coloca de volta na entrada e repete até sair [EOS].

Gerar um token de cada vez, usando os anteriores como entrada, se chama geração autorregressiva.

3.5A máscara causal

  • No treino, o decoder recebe a frase-alvo inteira de uma vez. A máscara esconde o futuro, para o modelo não "colar".
  • Os scores do futuro viram −∞ antes do softmax, e softmax(−∞) = 0.
  • Na prática é uma matriz triangular: cada token só se conecta a si e aos anteriores.

3.6Truques de treino

TruqueO que faz
Conexão residualSaída = x + f(x). A camada ajusta x em vez de reescrever tudo. Ajuda o gradiente a passar em redes profundas.
Layer normNormaliza as ativações. O treino converge melhor.
DropoutDesliga unidades ao acaso no treino, para o modelo não depender de poucas features.
Label smoothingO alvo deixa de ser 100% na palavra certa (ex.: 90%) e o resto se espalha pelo vocabulário. "Que dia lindo" e "que aula linda" podem estar ambas certas. Melhorou o BLEU na tradução.

3.8Exemplo completo: traduzindo uma frase

  1. Tokenizar a frase de origem:
    [BOS]Acuteteddy bearisreading[EOS]
  2. Embeddings: cada token busca seu vetor numa tabela aprendida (512 números) e soma a posição. Resultado: matriz X de 7 × 512.
  3. Encoder ×6: Q = XWQ, K = XWK, V = XWV em 8 cabeças, depois concat · WO, depois feed-forward 512 → 2048 → 512. A saída continua 7 × 512.
  1. O decoder recebe [BOS], faz a self-attention mascarada, a cross-attention com a saída do encoder e o feed-forward.
  2. Linear + softmax sobre o vocabulário escolhem "Un".
  3. A entrada vira [BOS] Un e sai "ours". Depois "en", "peluche", "mignon", "lit"... até sair [EOS].

Resultado: "Un ours en peluche mignon lit."

3.9Resumo da aula

  • Texto → tokens (BPE) → embeddings + posição.
  • Self-attention: softmax(QKT/√dk)V. Todos os tokens com todos, em paralelo.
  • Multi-head: várias atenções, depois concat + WO.
  • O encoder entende. O decoder gera token a token, com máscara e cross-attention.
  • O essencial é atenção + feed-forward (onde fica a maioria dos parâmetros) + dados de qualidade. O resto são truques para treinar melhor.
