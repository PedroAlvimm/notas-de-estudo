# Notas de Estudo

Anotações de estudo em estilo caderno escrito à mão, feitas em HTML.

**Ver online:** https://pedroalvimm.github.io/notas-de-estudo/

| Arquivo | Assunto | Conteúdo |
| --- | --- | --- |
| [git-e-github.html](git-e-github.html) | Git e GitHub | 2 páginas: as 4 áreas do Git, GitHub Flow, Pull Requests, Issues, GitHub Actions, fork, merge/squash/rebase, conflitos, commit em branch separada, como desfazer erros, segurança e boas práticas |
| [banco-de-dados-sql.html](banco-de-dados-sql.html) | Banco de Dados e SQL (MySQL 8) | 3 páginas: fundamentos, tipos de dados, chaves, normalização, CRUD, JOINs, agregação, subconsultas, índices, transações, views, procedures, triggers, permissões, backup e SQL Injection |

## Como ver

- **No navegador:** [Git e GitHub](https://pedroalvimm.github.io/notas-de-estudo/git-e-github.html) · [Banco de Dados e SQL](https://pedroalvimm.github.io/notas-de-estudo/banco-de-dados-sql.html)
- **No computador:** baixe o repositório (`git clone` ou *Code → Download ZIP*) e abra os arquivos `.html` no navegador.
- **Modo escuro:** as páginas seguem o tema claro ou escuro do sistema.

As fontes manuscritas (Caveat e Kalam) vêm do Google Fonts, então é preciso estar conectado à internet para vê-las.
